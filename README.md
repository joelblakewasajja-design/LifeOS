# 🧠 LifeOS: Your Personal AI Operating System

Built for the **Nebius x NVIDIA Global AI Hackathon** (Personal AI track).

LifeOS turns plain language, typed or spoken, into goals, tasks, and realistic plans.

[▶ Open in Colab](https://colab.research.google.com/github/joelblakewasajja-design/LifeOS/blob/main/LifeOS_Nebius.ipynb)

## Features
- 💬 AI coach that understands natural language and takes actions (add or complete goals and tasks)
- 📅 Smart Plan: builds a plan for the time you have
- 🎙️ Voice input with Whisper
- 💾 Persistent memory of goals and tasks
- 📊 Progress dashboard

## Tech stack
- Nebius Token Factory (OpenAI-compatible API)
- NVIDIA Nemotron open model
- Python, Gradio, Whisper

## Run it
1. Click the Open in Colab link above.
2. Add your `NEBIUS_API_KEY` in Colab Secrets (get one at tokenfactory.nebius.com).
3. Paste a Nemotron model ID into `MODEL`, then run all cells.
